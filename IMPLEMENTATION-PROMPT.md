# Implementation brief for an AI coding agent

Implement Sure Sente using this documentation as the working specification. Start by reading README.md, all linked specifications and repository instructions. Inspect existing code, authentication, theme, database and tests. If no project is provided, scaffold a new isolated project using the proposed stack; do not assume access to the founder's private repositories.

Deliver a simple responsive PWA for informal workers, households, businesses and authorised brokers. One account; Work, Services, Deals; Home, Find, Post, Messages, Me. Visible pay/price/commission. Guest browse, minimal worker profiles, guided listing wizard, scoped messaging, offers/quotes, outcomes and dispute reporting. Implement server persistence and authorisation; clearly label any demo data.

Follow the atomic phases in 13-IMPLEMENTATION-PLAN.md. Establish foundation and listings before work/services and brokerage. Preserve accepted term versions, buyer consent, attribution evidence, correct commission calculation, direct-payment reported-versus-received states, private documents and audit trails. No pay-to-apply, income guarantees, purchased identity verification, fake wallet balances or silent messages.

Support the entire category taxonomy but enable only approved pilot categories. Keep property, land, instalments, finance, healthcare and overseas recruitment disabled until their documented gates are satisfied. Never present a platform badge as title or legal verification.

Use proposed stack only where compatible; do not add microservices or Kubernetes for MVP. Build transparent rules before optional AI. Do not embed secrets. Add meaningful tests for permission boundaries, agreements, attribution concurrency, commissions and provider callbacks, plus mobile end-to-end journeys. Run relevant checks, document actual results, and do not claim deployment without observing it.

For each slice report changed behaviour, files, migration/config needs, verification results and remaining blockers. Do not stop at a proposal when implementation is authorised. Do not publish, spend money, contact third parties, or activate live fund custody based solely on this brief.
